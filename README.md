Getting started
Save the attached file somewhere easy to find, like your desktop, then double-click it to open in your web browser (Chrome, Edge, or Safari all work). That is the whole install. Use the same computer and browser each time, because it saves your work there.

Building a week

Set "Week of" at the top to the Sunday of the week you are scheduling. The day numbers and date range fill in automatically.
Click any cell and type the shift, like 10-3.
Hover over a cell to get three small buttons on the right:
RS highlights the shift in amber to show a roadshow is at that store that day.
O marks the day off (grays the cell).
The letter button cycles the text color black, blue, then red, for flagging anything you want to stand out.
To show someone covering another store, type that store's name into the cell, like Nampa, and it styles itself as coverage.
Add or remove people with the buttons in each store, add a store at the bottom, and rename any store or person by clicking its name.
Saving and reusing
It saves automatically as you type. When it is time for the next week, click "Copy to next week" and it duplicates everything onto the following Sunday so you only adjust what changed. Past weeks are in the "Saved weeks" dropdown.

Sending it out
Use "Print / PDF" for a clean printable copy you can save as a PDF and email. Or use "Snapshot image" to create a picture of the schedule, then right-click it and choose Save image to attach.
